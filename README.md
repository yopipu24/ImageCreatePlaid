ImageCreatePlaid
チェック柄・背景作成ツール

チェック柄の画像、色々な背景を自動で作成するツールです。

■使用方法
　・メニューから、「チェック柄」「背景」を選択
　・サイズを選択
　・柄を選択
　・各パラメータ（チェック幅、ブロック幅、色など）を設定
　・画像生成ボタンをクリック・タップ
　・画像が生成され、画面上に表示されるのでブラウザの機能で保存
